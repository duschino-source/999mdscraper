# Парсер 999.md

**Языки:** [English](README.md) · [Română](README.ro.md) · Русский

Асинхронный парсер объявлений 999.md на базе Playwright. Он хранит объявления и историю цен в SQLite и экспортирует результаты каждого запуска в CSV или JSON.

## Требования

- Python 3.10 или новее
- Chromium, установленный через Playwright

## Установка

В каталоге репозитория создайте и активируйте виртуальное окружение:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e .
python -m playwright install chromium
```

Чтобы использовать необязательный HTTP API, установите и его зависимости:

```powershell
python -m pip install -e ".[api]"
```

Для установки инструментов тестирования и сборки выполните `python -m pip install -e ".[api,dev]"`.

## Запуск из командной строки

```powershell
.\.venv\Scripts\999scraper.exe --url "https://999.md/ro/list/computers-and-office-equipment/video" --output listings.csv
```

По умолчанию парсер проходит страницы категории (до 999 страниц) и останавливается после двух страниц подряд без объявлений. История объявлений сохраняется в `scraper.db`, а найденные объявления со всех обработанных страниц экспортируются в `listings.csv`. Для экспорта в JSON укажите `--output listings.json`; параметр `--pages N` задаёт другой предел страниц, `--db PATH` — другой файл базы данных, а `--help` выводит все параметры. По умолчанию одновременно обрабатываются 3 страницы.

Если активировать виртуальное окружение командой `.\.venv\Scripts\Activate.ps1`, можно запускать `999scraper` без полного пути.

Можно запустить парсер из исходного каталога и без установки консольной команды:

```powershell
python -m scraper999.cli --pages 2 --output listings.csv
```

## Запуск API

```powershell
python -m uvicorn scraper999.api:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000/docs`, чтобы увидеть интерактивную документацию API. `POST /api/scrape` принимает URL категории 999.md, число страниц и уровень параллелизма. По умолчанию база данных хранится в `data/scraper.db`; задайте `SCRAPER_DATA_DIR` перед запуском, чтобы выбрать другой каталог. Запрос `GET /api/price-history?url=https://999.md/ro/12345678` возвращает историю изменений цены объявления. API предназначен для локального использования. Оставляйте его привязанным к localhost, если не добавили аутентификацию и другие меры защиты для развёртывания.

## Примечания

- Установка браузера выполняется отдельно. При запуске парсер не скачивает браузер и не использует закрытые API Playwright.
- Принимаются только URL доменов `999.md` и `www.999.md`.
- SQLite хранит время первого и последнего обнаружения объявления и отмечает снижение цены.
- История цен сохраняет каждое обнаруженное изменение. При обновлении существующей базы последняя известная цена становится первой записью истории.
- Страницы проверяются по порядку. Парсер пропускает одну пустую страницу и останавливается после двух пустых страниц подряд.
- API не принимает путь к файлу базы данных в запросе, поэтому клиент не может произвольно выбирать файл для записи.
- Структура страниц и антибот-защита 999.md могут меняться; селекторы при необходимости придётся обновить.
